# Аудит и проверка

```powershell
python -m pip install -e ".[api,dev,export]"
python -m pytest
python -m ruff check slide_agent tests examples/run_dataset.py examples/run_baseline.py
python -m compileall -q slide_agent
git diff --check
```

`test_actual_office_export` запускает настоящий LibreOffice, проверяет число страниц
PDF, PNG и SVG в HTML, а также неизменность исходного PPTX. Без LibreOffice этот
интеграционный тест явно пропускается. Unit-тесты не требуют PowerPoint или LLM.

| Область | Что проверяется |
|---|---|
| Импорт | Кеш по хэшу, PPTX/PDF, совпадающие имена разных макетов |
| Композиция | Нативные объекты, перенос стиля, геометрия, сохранение контента |
| Варианты | Одинаковый план содержания, три результата, неизменность шаблона |
| Ремонт | Новый результат, исходник неизменен, XML невыбранных слайдов не меняется |
| Статусы | Провал QA не переводит задачу в completed; CLI возвращает ошибку |
| Экспорт | Реальный office render, страницы PDF, SVG HTML, отсутствие renderer |
| API | Загрузка, фоновые задачи, варианты, скачивание, недопустимый формат |
| Inference | Mock-проверка транспорта и контракта; реальная модель не проверена |

Детерминированные проверки: ZIP/OOXML, число слайдов, выход блоков за холст,
оценка переполнения текста, пересечения текстовых блоков, шрифты вне шаблона,
пустые слайды, утечки PDF-фрагментов, заглушки, буквальные дубликаты текста,
лимиты списков/таблиц/рядов диаграмм. Каждый issue получает ID, номер слайда,
координаты в дюймах и признак доступности автоматического исправления.

Геометрический расчёт переполнения — оценка, а не измерение всех глифов офисным
движком. Размеры таблиц и длина тезисов дают предупреждения, не доказательство
плохой композиции. Сравнение покрытия исходного текста не доказывает истинность
фактов и может требовать ручной проверки после перефразирования.

Контекстуальные вопросы из приложения ТЗ (смысл заголовка, логика повествования,
релевантность картинок, достоверность фактов) **не реализованы как VLM-аудит**.
В отчёте явно указан `contextual_audit.status=not_run`.

Ремонт выбранных ошибок геометрии повторно выбирает макет; он не гарантирует
устранение каждой проблемы и не сокращает исходные факты. Новая версия снова
проверяется, оставшиеся ошибки отображаются. Оригинал результата сохраняется.

Для предоставленных PPTX: `python examples/run_dataset.py`. Это технический
offline-прогон на синтетических материалах. Не следует выдавать его за проверку
качества модели, официального контент-пакета или финального неизвестного шаблона.

с хэшами исходников, временем, статусами и проверкой веб-интерфейса в Chrome.
