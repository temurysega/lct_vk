# История версий

В проекте три независимые версии:

| Что | Где | Когда меняется |
|---|---|---|
| Версия сервиса | `pyproject.toml`, `slide_agent.__version__`, ответ `/health` и Swagger; тег Git `vX.Y.Z` | Выпуск для показа или сдачи |
| Версия workflow — промптов, скиллов и агентов | `PROMPT_VERSION` в `slide_agent/prompt_config.py` | Любое изменение промпта: новый текст пишется в новый файл `prompts/<имя>-vN.txt`, прежние файлы остаются |
| Версия схемы анализа шаблона | `ANALYSIS_SCHEMA_VERSION` в `slide_agent/analyzer.py` | Изменение формата `design_system.json` и `pattern_catalog.json`; старый кэш пересоздаётся |

Версия workflow, имена активных файлов промптов, их SHA-256 и хэш словаря
пиктограмм записываются в `manifest.json` каждой колоды и в
`reports/final-dataset/evidence.json`, поэтому любой результат можно связать с
точными инструкциями модели. Детерминированные правила — код; их версия —
ревизия Git, которую `examples/run_dataset.py` записывает в отчёт прогона.

## 1.1.0 — 29.09.2026 (workflow 1.11.0)

Проверка на шаблонах, которых сервис не видел (два публичных шаблона Slidesgo и
синтетический шаблон из `examples/create_demo_assets.py`), нашла дефекты, которые
QA = 100 не отмечал. Колоды в `deliverables/` по-прежнему собраны кодом
`f96244b`: исходные шаблоны VK для повторного прогона на этой версии недоступны.

- Шкала кеглей (схема анализа 1.8): кегли плейсхолдеров макетов и мастера
  (экспорт Google Slides хранит кегль заголовка в плейсхолдере мастера) входят в
  `observed_sizes_pt`. Раньше шкала шаблона Outer Galaxies была 12/10/8 pt, и
  заголовки прижимались к 12 pt.
- Длинный заголовок-вывод получает вторую строку до уменьшения кегля: рамка
  растёт вниз в свободное место, пустой текстовый слот макета сдвигается (до
  четверти высоты), орнаменты макета в полосе заголовка сужают рамку.
- Служебные страницы шаблона (инструкции, шрифты и цвета, ресурсы, наборы
  иконок) не становятся образцами макетов. Финальный слайд распознаётся по
  короткой строке «Спасибо» / «Thanks!» / «Questions?», а карточка без текста с
  логотипом автора шаблона в конце — нет.
- Слоты образца, которые план не заполнил (второй заголовок, подпись колонки),
  очищаются: раньше на финальном слайде оставалось «Mission / Vision / Venus has
  a beautiful name».
- Новые детерминированные проверки: `template_sample_text` (текст образца
  шаблона на слайде) и `image_text_overlap` (сгенерированный текст под
  сгенерированной картинкой); обе исправимы сменой макета.
- Текст образца больше не выходит из зоны рядом со слотом картинки.
- Кегль подгоняется так, чтобы самое длинное слово помещалось в ширину рамки:
  в узкой боковой колонке заголовок больше не рвётся посреди слова
  («специалист / у»). Новая проверка `word_split_risk` отмечает такие слова.
- Пересборка полупустых слайдов после рендера не может ухудшить колоду: если все
  новые макеты хуже, восстанавливается колода первого прохода.
- Низкий контраст текста, который рисует сам макет шаблона (строка кредитов),
  отмечается как `info` и не снижает балл сгенерированного контента.
- Без явного числа слайдов колода строится на 10–15 слайдов (промпт
  `planner-v4`, офлайн-планировщик); меньше — только при нехватке материала.
- `--json` у CLI больше не портится предупреждением PyMuPDF об устаревшем
  модуле `fitz`.

## 1.0.0 — 28.09.2026 (workflow 1.10.0)

Первая зафиксированная версия для сдачи. Опубликованные в `deliverables/`
колоды собраны кодом `f96244b` (workflow 1.9.0) и прошли все строгие критерии;
прогон на коде 1.0.0 с теми же критериями ещё не выполнен.

- Визуальный аудит по картинке итогового слайда отвечает на вопросы
  «Валидации контента» из Приложения 1 ТЗ (1–8 и 10: да / нет / неприменимо)
  и проверен на настоящей модели: Qwen3.5-9B с проектором изображений
  `mmproj-F16.gguf`. Промпт вынесен из кода в `prompts/vision-audit-v1.txt`.
- Правила фактов брифа: «пилот запущен» при просьбе его одобрить, выдуманные
  числа; упорная ошибка модели исправляется детерминированно или останавливает
  сборку.
- Английские слова в русской колоде возвращаются модели на этапах структуры,
  текста и переписи слайда.
- Полупустые слайды: схема переходит на макет с крупной зоной и растягивается,
  тезисы слайда «data» без данных становятся карточками, список параметров не
  рисуется циклом или пирамидой, пирамида из двух уровней становится карточками;
  фото полупустого слайда растягивается на свободное место рядом;
  до трёх повторов макета на вариант. Схема, которую модель вернула при
  переписи слайда, проходит те же правила, что и при планировании.
- Подгонка длинной обложки согласована с оценкой переполнения QA; кегль
  округляется по шкале шаблона вниз.
- Быстрее: контраст исправляется только на финальном рендере.
- Установка модели: проектор изображений закреплён в профиле с SHA-256,
  загрузка продолжается после обрыва соединения; `start-llama.ps1 -Vision`
  поднимает сервер с проектором.
- Документация: полный список тестов в AUDIT.md, история живых прогонов в
  `reports/final-dataset/README.md`.
