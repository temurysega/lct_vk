# Модели и инференс

Для запуска на A100 подготовлен [Colab notebook](examples/BrandDeck_A100_Inference.ipynb)
с **Qwen2.5-VL-7B-Instruct** (текст и изображения, 7B, Apache 2.0).
Источник характеристик: [официальная model card](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct).
Notebook поднимает [vLLM](https://docs.vllm.ai/en/latest/cli/serve/) в отдельном venv,
фиксирует revision весов и версии пакетов, проверяет JSON-ответ и даёт временный
HTTPS-адрес через [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/).
API защищён пользовательским ключом; запрос без ключа должен быть отклонён.
Начальные параметры: BF16, контекст 32768, 1 последовательность, до 4 изображений,
85% VRAM. Это стартовая конфигурация, а не замер производительности.

На GPU notebook ещё не запускался, веса локально не скачивались. В проверенном
режиме планировщик детерминированный (`offline`); GPU не используется.
Нельзя интерпретировать результаты offline-тестов как оценку качества LLM/VLM.

Клиент `slide_agent/llm.py` поддерживает совместимый HTTP `/chat/completions`.
Конфигурация задаётся переменными окружения:

```powershell
$env:INFERENCE_BASE_URL="https://your-inference-host/v1"
$env:INFERENCE_MODEL="your-served-model-id"
$env:INFERENCE_API_KEY="your-token"
$env:INFERENCE_VISION="1"
```

Ключ не хранится в исходниках и отчётах. Текстовая модель планирует структуру и
визуализации в JSON. При включённом vision анализатор может передать до четырёх
превью для качественных рекомендаций. Цвета, шрифты и координаты остаются
основанными на OOXML. Ошибка модели приводит к явно обозначенному `fallback`.

По предоставленному ТЗ допускаются модели с открытыми весами и лицензией
Apache 2.0/MIT, до 35B; для дополнительного задания text-to-image указан предел
20B. Для финалистов требуется организаторский inference. Соответствие конкретной
модели должен подтверждать её model card: URL, лицензия, версия, число параметров,
precision/quantization и фактическая конфигурация сервера. Эти поля пока не
заполнены результатами реального запуска; предложенный профиль Qwen нужно проверить
на доступной A100. Notebook сохраняет revision и версии после установки.

A100 в Colab можно использовать как отдельный inference-сервер. Перед запуском
проверьте доступную VRAM (40/80 GB) командой `nvidia-smi` в notebook; при нехватке
памяти уменьшите контекст и число изображений в запросе.
Обучение на трёх шаблонах не требуется: шаблоны разбираются при загрузке, а новый
стиль должен работать без переобучения. Разбор OOXML, сборка и экспорт работают
на CPU. Реальные задержки и память выбранной модели ещё не измерялись.

Семантический VLM-аудит и генерация изображений пока отсутствуют. Использование
закрытых моделей по умолчанию не заложено; клиент не проверяет лицензию модели
автоматически, поэтому её нужно зафиксировать перед конкурсным запуском.
