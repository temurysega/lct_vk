# predel — backend

FastAPI: `backend.main:app`. Старый импорт `slide_agent.api:app` и команда
`branddeck serve` сохранены для совместимости. Движок презентаций остаётся в
`slide_agent/`; обучение — в `training/`.

```bash
python -m pip install -e ".[api,dev]"
npm ci --prefix frontend
npm run build --prefix frontend
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

При запуске автоматически создаются SQLite-база и пользовательские каталоги
в `BRANDDECK_WORKSPACE` (по умолчанию `slide-workspace/`).

Маршруты `/` и `/studio` отдают React SPA из `frontend/dist/index.html`,
а `/assets` — только собранные ресурсы. Исходники frontend не публикуются.
Если сборки нет, страница возвращает HTTP 503 с командой сборки; API и CLI
продолжают работать. Для разработки UI запустите `npm run dev --prefix frontend`:
Vite проксирует API на порт 8000 без изменения Origin.

## Аккаунты

Регистрация принимает только имя пользователя, пароль и должность; email не нужен.
Имена нечувствительны к регистру. Пароли хешируются scrypt с индивидуальной солью,
сессии хранятся на сервере; в cookie передаётся случайный токен с HttpOnly и SameSite.
В базе хранится SHA-256 токена. Сессия действует семь дней, выход отзывает её.
Вход ограничен 20 запросами, регистрация — 10 запросами с одного IP за 10 минут.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| POST | `/api/auth/register` | `{username, password, position}`, создание аккаунта и сессии |
| POST | `/api/auth/login` | `{username, password}`, создание сессии |
| GET | `/api/auth/me` | Текущий пользователь |
| POST | `/api/auth/logout` | Отзыв сессии |
| GET | `/api/config` | Настроена ли модель, без ключей и адресов провайдера |

Все маршруты `/v1/*` требуют сессию. Для CLI HTTP-запросов используйте cookie jar:

```bash
curl -c cookies.txt -H 'Content-Type: application/json' \
  -d '{"username":"designer","password":"replace-with-a-strong-password","position":"Дизайнер"}' \
  http://127.0.0.1:8000/api/auth/register
curl -b cookies.txt http://127.0.0.1:8000/v1/templates
```

`cookies.txt` содержит сессию — не добавляйте его в Git.
В Swagger сначала выполните register/login, затем остальные запросы из того же браузера.

Каждый аккаунт использует `users/<id>/` для шаблонов, jobs, batches и презентаций.
Контекст изолирован через ContextVar на время ASGI-запроса, включая фоновые задачи.
Текст, отправленный через HTTP, никогда не трактуется как путь к файлу сервера.
CLI продолжает работать в явно указанном workspace и не требует аккаунта.
Старые CLI-результаты намеренно не становятся общедоступными после регистрации:
загрузите необходимые шаблоны в студию своего аккаунта.

## Модель и экспорт

После завершения обучения подключите модель через существующие `INFERENCE_*`.
Без настроенной модели студия использует детерминированный режим и просит полный
текст материалов. Наличие настроек не является проверкой доступности inference.
Генерация, обучение и формат модели не менялись.
Для PDF/HTML/превью нужны LibreOffice и зависимости `[export]`;
для DOCX/XLSX/PDF-контента — `[documents]`.

Для публичного развёртывания используйте HTTPS, `PREDEL_SECURE_COOKIES=1`,
доверенную конфигурацию reverse proxy и постоянный volume для workspace.
Приложение отклоняет изменяющие запросы с чужим Origin.
Текущие фоновые задачи выполняются в процессе API; перезапуск прерывает
незавершённую генерацию. Очередь, пользовательские квоты, восстановление пароля
и изоляция обработчиков документов в отдельных процессах пока не реализованы.
