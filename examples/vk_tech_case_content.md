# BrandDeck AI — презентации в стиле произвольного шаблона

## Проблема
- Генеративные модели уверенно создают содержание, но плохо воспроизводят фирменную композицию.
- Ручная адаптация корпоративного шаблона занимает часы и требует дизайнера.
- Простая подстановка текста не учитывает назначение и ёмкость разных типов слайдов.

## Цель решения
- Сократить подготовку презентации с часов до минут.
- Сохранять единый стандарт оформления независимо от автора.
- Работать с новым PPTX или PDF без заранее зашитого фирменного сценария.

## Анализ шаблона
- OOXML-парсер извлекает masters, layouts, placeholders, геометрию, фоны и изображения.
- Дизайн-токены нормализуются в отдельный машинно-читаемый контракт.
- Визуальные превью помогают модели определить иерархию, плотность и ритм композиции.

## Каталог паттернов
- Система выделяет cover, section, content, comparison, data, image и closing.
- Паттерны извлекаются как из layouts, так и из реальных слайдов-примеров.
- Для каждого паттерна сохраняются ёмкость, зоны контента и связь с исходным master.

## AI-оркестрация
- OpenAI-compatible Inference API превращает исходный материал в структурированный deck plan.
- Каждый смысловой блок сопоставляется с подходящим паттерном текущего шаблона.
- Ответ модели проходит allow-list, ограничения длины и проверку типов данных.

## Сборка презентации
- Исходные masters, backgrounds, media relationships и элементы бренда сохраняются.
- Текст остаётся редактируемым в PowerPoint.
- Таблицы, диаграммы, карточки метрик и таймлайны создаются как нативные объекты.

## Контроль качества
- Проверяется целостность ZIP и OOXML-пакета.
- Контролируются границы объектов, плотность текста, число слайдов и шрифты.
- При критической ошибке контент автоматически уплотняется и презентация собирается повторно.

## Результаты проверки
- Пятнадцать автоматических тестов проходят успешно.
- REST API отвечает на health-check.
- Основная проверка выполнена напрямую на 14-страничной презентации VK Tech за I квартал 2026 года.
- Дополнительные презентации других стилей подтверждают отсутствие зашитого VK Tech-сценария.
- Все создаваемые материалы сопровождаются manifest и QA-отчётом.

## Итоговый продукт
- Open-source CLI и REST API.
- Воспроизводимый анализ произвольного PPTX или PDF.
- Готовая презентация без обязательного ручного редактирования.
- Возможность повторного использования каждого проанализированного шаблона.
