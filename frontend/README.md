# predel — frontend

Статический клиент без сборки и внешних JavaScript-зависимостей:

- `index.html` — главная, короткий бриф и регистрация/вход.
- `studio.html` — загрузка шаблона, генерация, сравнение, аудит и экспорт.
- `site.js` — аккаунт, переход с брифом в студию, анимации.
- `app.js` — работа с API, восстановление фонового задания и результаты.
- `style.css` — общая адаптивная дизайн-система, включая reduced-motion.

Запуск из корня: `python -m uvicorn backend.main:app --reload`.
Откройте `http://127.0.0.1:8000`. Backend раздаёт клиент и API с одного origin;
отдельный Node-сервер для разработки и CORS не нужны.

Визуальный ориентир — [Wonderslide](https://wonderslide.com/): тёмная плоскость,
мятный акцент, крупная типографика и каскад презентаций. Структура сокращена по
примеру [Sokratic](https://sokratic.ru/en). Композиции слайдов сделаны в HTML/CSS;
их содержание демонстрационное, это не обещание результата генерации.

Шрифт Manrope хранится локально; лицензия — `fonts/OFL.txt`.
Иллюстративные фотографии загружены с Unsplash:
[архитектура](https://images.unsplash.com/photo-1486406146926-c627a92ad1ab),
[рабочее пространство](https://images.unsplash.com/photo-1497366754035-f200968a6e72).
Главная не обращается к внешним CDN, не использует аналитику или трекеры.

## Проверка в браузере

`tests/browser_smoke.cjs` проверяет регистрацию из трёх полей, перенос брифа,
загрузку PPTX, три варианта, скачивание, историю, мобильную ширину, выход,
ошибочный пароль и повторный вход. Запускайте против отдельного тестового
workspace: сценарий создаёт аккаунт и презентацию.

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
PREDEL_TEST_TEMPLATE=/absolute/path/to/template.pptx node tests/browser_smoke.cjs
```

По умолчанию сервер — `http://127.0.0.1:8000`; другой адрес задаётся через
`PREDEL_BASE_URL`. Для установленного Chrome: `PREDEL_BROWSER_CHANNEL=chrome`.
Скриншоты сохраняются в отдельный временный каталог, путь выводится после прогона.
