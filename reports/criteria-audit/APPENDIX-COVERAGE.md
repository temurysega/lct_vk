# Покрытие Приложения 1

Источник: [официальное задание, PDF с. 6–7](sources/official-task.pdf#page=6). Это **ориентир**, который ТЗ разрешает расширять и сокращать с обоснованием. Таблица описывает покрытие конкретной проверки, а не вводит дополнительные обязательные баллы. Наличие функции учтено только вместе с исполненными тестами или новым артефактом; остающиеся пределы указаны отдельно.

Статусы: **выполнено** — проверка срабатывала в проверенном сценарии; **частично** — эвристика/ограниченная область или обнаруженный пропуск; **не выполнено** — соответствующий контроль не найден; **не проверено** — нет нужного реального запуска. Ни один статус не обещает выявить все возможные дефекты.

## Смысловая часть

На [PDF с. 7](sources/official-task.pdf#page=7) входом этих вопросов названа **картинка слайда**. Текущий `contextual_audit.py:58` получает текст source/plan; при `INFERENCE_CONTEXT_AUDIT != 1` или отсутствии клиента возвращает `not_run`. Разрешённые модельные codes: `unsupported_claim`, `repeated_message`, `title_not_claim`; результат помечается предложением для человека. В этом аудите реальных вызовов не было. Нижеследующие экспертные наблюдения нельзя выдавать за выполненную продуктом VLM-проверку.

| Точный вопрос | Покрытие автоматикой / статус | Экспертное наблюдение на новых файлах |
|---|---|---|
| «Заголовок содержит вывод, а не просто называет тему?» | **не проверено** с моделью; текстовый `title_not_claim` реализован, VLM нет | В исходном материале содержательные заголовки уже сформулированы утверждениями; генератор в offline их сохраняет |
| «Содержимое слайда соответствует заголовку?» | **не выполнено** как отдельная проверка картинки; частично пересекается с общим текстовым grounding | На VK-файлах соответствует; у внешних шаблонов ухудшается визуальная иерархия, а не фактологический состав |
| «Слайд пересказывается одним предложением?» | **не выполнено** как отдельный контроль | Большинство слайдов имеют одну тему, часть длинных карточек перегружена словами |
| «Все цифры и факты со слайда есть в исходных материалах?» | **частично**: literal coverage и числа; модельная оценка **не проверена** | 38 единиц сохранены; добавленных результатов ещё не проведённого пилота не найдено. Это проверка соответствия данному тексту, не истинности самого текста |
| «На слайде есть содержание, а не только заголовок?» | **частично**, structural title_only/empty | В приёмочных файлах содержание есть. На Brutalism полезный текст занимает слишком мало пространства |
| «Картинки и иконки относятся к теме слайда?» | **частично**: lexical matching и icon keywords, без VLM результата | Фото специалистов на слайде 3 релевантно; картинка серверной осталась unplaced. Некоторые общие пиктограммы условны; crop не всегда удачен |
| «Нет служебного мусора: реплик спикера, кусков промпта?» | **частично**, regex placeholders | В основных offline-колодах явных кусков промпта/реплик не найдено; качество реального модельного вывода не проверено |
| «Текст без опечаток?» | **частично**, только mixed-script эвристика; общего spelling-контроля нет | В заданном русском материале явных опечаток не замечено. Разреженные глифы Onocom и переносы pie — дефекты отображения, не орфографии |
| «Вся колода на одном языке?» | **частично**, `audit.py:38` для BrandDeck text shapes | Основные колоды русские. В контрольном pie присутствует английское `Values`, которое не отражено language warning |
| «Все строки таблицы и элементы легенды работают на мысль слайда?» | **не выполнено** как отдельный визуально-смысловой контроль | Ручной компонентный план содержательно уместен; легенда pie читается плохо. Выбор таблицы/диаграммы настоящей моделью не проверен |
| «Соседние слайды связаны между собой по логике?» | **частично** как текстовый поиск повторов; live **не проверен** | Сохранена логика исходника: проблема → пользователи → решение → процесс → ограничения → пилот → метрики → запрос ресурсов |

Расхождение с ориентиром допустимо лишь с обоснованием согласно ТЗ. Честная маркировка `not_run` полезна, но не заменяет демонстрацию того, какие контекстные проверки реально выполняются и почему выбран такой объём.
