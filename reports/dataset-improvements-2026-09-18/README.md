# Проверка трёх предоставленных шаблонов

Проверка от 18 сентября 2026 года. [Машиночитаемая сводка](summary.json),
[контактный лист](slides.png), [веб-интерфейс](web.png).

Датасет — три PPTX из `данные`. Все исходники сохранены без изменений; SHA-256
указаны в сводке. Для наполнения использован явно синтетический
`examples/baseline_content.md`. Обучения и запросов к модели в этом прогоне нет.

| Шаблон | Результат | Время трёх вариантов с экспортом |
|---|---|---|
| VK Tech | 3 × 10 слайдов | 32,1 с |
| VK WorkSpace | 3 × 10 слайдов | 22,8 с |
| VK Education | 3 × 10 слайдов | 20,9 с |

У всех девяти результатов прошли структурные проверки и экспорт через
LibreOffice в PDF/HTML; подготовлены PNG-превью. Каждый шаблон дал три разные
последовательности макетов при одинаковом плане содержания. Буквальное покрытие
исходного текста полное. В двух результатах есть информационное замечание
о декоративных элементах шаблона за границей слайда; ошибок и предупреждений нет.

Проверки кода: 42 теста прошли, в том числе реальная конвертация LibreOffice,
сохранение исходника и XML невыбранных слайдов при точечном исправлении.
Ruff, compileall, проверка синтаксиса JavaScript и `git diff --check` прошли.
Единственное предупреждение pytest — уведомление Starlette о переходе с httpx
на httpx2; сбоя проверки нет.

В Chrome 153 проверены загрузка страницы с тремя шаблонами, открытие истории,
переключение вариантов, скачивание PPTX/PDF/HTML и генерация через форму.
Дополнительная генерация трёх вариантов через UI заняла 39,1 с.
При ширине 390 px горизонтального переполнения не было. Ошибок JavaScript нет.

## Воспроизведение

```powershell
python -m pip install -e ".[api,dev,export]"
python -m pytest
python examples/run_dataset.py
python -m slide_agent --workspace slide-workspace/dataset serve
```

Для экспорта нужен LibreOffice. Галерея результатов создаётся в
`slide-workspace/dataset/index.html`, полные отчёты — в `dataset_report.json`
и каталогах отдельных презентаций. Сгенерированные PPTX не включены в git.

## Границы результата

Структурный QA не доказывает визуальное или смысловое качество. В некоторых
композициях остаются свободные карточки и мелкий текст; подбор макетов
эвристический. Проверка фактов, логики повествования и релевантности изображений
моделью пока отсутствует (`contextual_audit.status=not_run`).

Замеры относятся к локальному offline-режиму и не отражают скорость модели.
Неизвестный финальный шаблон и организаторский API этим прогоном не проверялись.
