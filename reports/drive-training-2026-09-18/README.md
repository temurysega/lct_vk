# Комплект обучения через Google Drive

Проверено 18.09.2026. Реального запуска Qwen 7B на A100 в этой среде не было;
обученных пользовательских весов пока нет.

- [Датасет](dataset.json): 297 обучающих строк, 88 уникальных групп, 27 проверочных
  примеров. VK WorkSpace целиком исключён из обучения. Тексты общих групп
  исключены из проверки. Контрольные суммы трёх исходных PPTX не изменились.
- [Настоящий токенизатор Qwen](tokenizer-report.json): проверены все 324 строки,
  длина 837–1088 токенов при лимите 3072, обрезаний нет. Базовые веса не скачивались.
- [Тест LoRA на CPU](cpu-report.json): две итерации Trainer на маленькой случайной
  Qwen2-модели, параметры адаптера изменились, после сохранения и загрузки logits
  совпали. Это проверка механизма, не обучение полезной модели и не проверка NF4/CUDA.
- 49 тестов проекта прошли. Новые тесты проверяют разделение данных, маску loss,
  ограничение длины, загрузочный notebook, вызов адаптера и откат при плохом ответе.

Исходники генератора комплекта — `training/prepare_drive.py`. Сборка:

```powershell
python training/build_notebook.py
python -m training.prepare_drive
```

Папка `../gdrive/lct` содержит около 59 MB: исходные шаблоны, данные, скрипты,
инструкцию и notebook. Её пользователь загружает в свой Google Drive.
Подключения к Google-аккаунту и Colab runtime у локального агента нет.

Метки обозначают исходный exemplar среди кандидатов, а не человеческую оценку
лучшего оформления. Перестановки кандидатов не считаются независимыми данными.
Даже рост точности по этим меткам требует отдельного визуального сравнения.
Notebook сохраняет базовые и итоговые ответы, сравнивает их с эвристиками и
сохраняет версию базы, параметры, зависимости, GPU и длительность.
