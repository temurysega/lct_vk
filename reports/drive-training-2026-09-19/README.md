# Обучение через Drive: проверка сохранения и продолжения

Подготовлен комплект `../gdrive/lct` из `../task+data/Датасет` для отдельного
Google-аккаунта с A100. GitHub в Colab не требуется. PDF с условиями не включён
в обучающие данные; отдельный контент-пакет в предоставленной папке отсутствует.

Данные: 297 обучающих строк, 88 уникальных групп, 27 проверочных строк.
VK Tech и VK Education используются для обучения, VK WorkSpace — для проверки.
Перестановки кандидатов являются аугментацией, метки получены автоматически.

Исправлено сохранение: полный Trainer checkpoint копируется на Drive после
шага 1, каждых 10 шагов и в конце эпохи. Сохраняются оптимизатор, scheduler,
RNG, состояние Trainer, адаптер и токенизатор. Копии проверяются по SHA-256;
маркер COMPLETE.json публикуется последним. Две последние целые копии сохраняются.
Повторное событие сохранения на том же шаге не занимает второй резервный слот.
`--resume auto` восстанавливает последний запуск, `none` создаёт новый.
Итоговый `adapter.zip` содержит переносимые веса, конфигурацию, токенизатор,
версию базы, метрики, manifest датасета и контрольные суммы.

Проверки 19.09.2026:

- `pytest`: 53 passed, 1 skipped. Для временных файлов использована новая папка
  внутри `slide-workspace`, поскольку стандартный Windows Temp отклонил доступ.
- Пять тестов чекпоинтов: восстановление, несовместимые настройки, повреждённая
  и незавершённая загрузка, ротация копий, выбор запуска.
- `python -m training.check_cpu`: маленькая случайная Qwen2, 4 шага на CPU;
  остановка после шага 2, публикация на имитируемый Drive, восстановление в новой
  локальной папке. Итоговые обучаемые параметры совпали с непрерывным запуском
  при `atol=1e-6`; проверены шаги оптимизатора, scheduler и повторная загрузка весов.
- CPU-окружение: torch 2.13.0+cu126, transformers 4.57.1, peft 0.17.1,
  accelerate 1.10.1. Colab использует отдельный requirements с torch 2.8.0.
- Синтаксис notebook, compileall и Ruff для изменённых Python-файлов проверены.

CPU-проверка не тестирует NF4/CUDA, реальный Google Drive или обучение Qwen 7B.
Полезных обученных весов пока нет; A100-прогон и визуальная оценка нужны отдельно.
Инструкция переноса и подключения: [training/DRIVE_README.md](../../training/DRIVE_README.md).
