# predel: React и визуальная система VK / Butter

## Реализовано

- Frontend полностью переведён на React 19 + TypeScript + Vite: главная,
  авторизация, рабочая студия, история, задания, аудит, исправления и скачивание.
- Отдельный FastAPI backend сохранён. Модель, обучение и pipeline не изменены.
- Бело-синий визуальный язык: плавающая навигация, оригинальная CGI-иллюстрация,
  крупная типографика, интерактивные примеры, короткий бриф и адаптивная студия.
  Ориентир по композиции — [Butter](https://www.butter.video/), палитра — в духе VK.
- По frontend-skill упрощена иерархия: один визуальный акцент на секцию,
  минимум декоративных панелей, осмысленные анимации, reduced-motion.
- Регистрация: имя пользователя, пароль, должность. База существующих аккаунтов
  не изменялась; локальный аккаунт demo сохранён.
- FastAPI раздаёт Vite dist с единым origin, исходники не публикуются.
  Dockerfile получил отдельный Node build stage. Wheel содержит React bundle.
- Старые статические app.js/site.js/studio.html/style.css заменены React-кодом.
  Старые версии доступны в предыдущем Git-коммите; шрифты и фото перенесены.

Browser smoke: три поля регистрации, перенос брифа, загрузка PPTX, три варианта
по пять слайдов без модели, переключение варианта, скачивание PPTX, история
после перезагрузки, мобильная ширина, выход, отказ неверному паролю, повторный вход.
JS-ошибок не обнаружено. Использован отдельный временный workspace.

UI-тест: отсутствие горизонтального переполнения, CTA внутри первого экрана,
иллюстрация не пересекается с текстом, интерактивные примеры, мобильное меню,
закрытие модального окна по Escape. Автоматическая проверка не заменяет полный
ручной аудит доступности и испытания во всех браузерах.

## Ограничения

- LibreOffice отсутствует локально, поэтому один интеграционный тест пропущен;
  PDF/HTML/реальные превью здесь не подтверждены.
- Docker daemon не запущен. Dockerfile обновлён, но контейнерная сборка не выполнена.
- Генерация проверялась без модели. Подключение обученной модели, её качество,
  смысловой/VLM-аудит и время генерации требуют отдельной проверки.
- Редизайн закрывает несоответствие стеку UI, но не означает максимальный балл
  по всем критериям задачи.
