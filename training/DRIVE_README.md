# Папка lct для Google Drive

Загрузите **эту папку целиком** в «Мой диск» Google-аккаунта, где доступна A100.
Должно получиться `Мой диск/lct/data/train.jsonl`, а не `lct/lct/data/train.jsonl`.
Привязывать GitHub не нужно. Базовая модель общедоступна и скачивается автоматически.

1. Войдите в Colab под аккаунтом с A100.
2. Через «Файл → Загрузить блокнот» откройте `BrandDeck_A100_Training_Drive.ipynb`.
3. Выберите GPU A100 в настройках среды.
4. Выполняйте разделы 1–4: проверка файлов, установка, обучение, результаты.
5. Разделы 5–7 загружают сохранённые веса и подключают модель к приложению.
6. Ячейку «Остановка» выполняйте после работы, не запускайте весь notebook одной командой.

```text
lct/
  BrandDeck_A100_Training_Drive.ipynb
  README.md
  templates/                 исходные три PPTX
  data/
    train.jsonl              примеры обучения
    validation.jsonl         отдельный шаблон для проверки
    manifest.json            происхождение, количество, SHA-256
  scripts/
    train_layout.py
    data_utils.py
    requirements-a100.txt
  weights/                   заполняется после обучения
  runs/                      замеры и резервные копии адаптера
```

Обучается QLoRA-адаптер **выбора макета**, база — Qwen2.5-7B-Instruct.
Это текстовая модель; для этого профиля `INFERENCE_VISION=0`.
Данные получены из текста и структуры трёх PPTX. Разметка слабая: исходный
макет слайда считается целевым среди кандидатов, хотя другой макет тоже может
подходить. Поэтому точность на этих метках не равна качеству презентаций.
Перестановки кандидатов — аугментация, они не увеличивают число независимых слайдов.

В обучение идут VK Tech и VK Education. VK WorkSpace оставлен для проверки;
совпадающие группы текстов убраны из проверки. Три стиля — маленький эксперимент,
не доказательство переноса на произвольный бренд. Notebook сравнивает адаптер
с базовой моделью и текущими эвристиками, не обещая улучшения.

После успешного обучения:

- `weights/<run_id>/adapter/adapter_model.safetensors` — дополнительные веса;
- `weights/<run_id>/adapter/adapter_config.json` — параметры адаптера;
- `weights/<run_id>/adapter.zip` — архив для скачивания;
- `weights/latest.json` — ссылка на последний завершённый запуск;
- `runs/<run_id>/metrics.json` — сравнение до/после и с эвристиками;
- `runs/<run_id>/run.json` — точная версия базы, GPU, настройки и время.

Адаптер загружается **вместе с базовой моделью той же версии**. Самостоятельно он
не работает. Полную копию базовых весов хранить на Drive не требуется.
Для нового запуска API без повторного обучения: раздел 1, затем разделы 4–7.
На локальном компьютере выбирайте `INFERENCE_MODEL=Qwen/Qwen2.5-7B-Instruct`,
а для адаптера — отдельную переменную `INFERENCE_LAYOUT_MODEL=lct-layout`.

Комплект подготовлен и проверен локально; фактическое обучение на A100 ещё
не выполнялось. GPU-совместимость и качество станут известны после запуска.
